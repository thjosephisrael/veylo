### SLIDE 05 — HOW IT WORKS
*Allocated Time: 30 Seconds • Warm Off-White Canvas `#F8FAFC`*

- **Visual Architecture:**
  - Headline:
    - `How it works under the hood.` (Midnight Ink `#111B32`, Manrope ExtraBold 56px)
    - `Open Payments for discovery. Interledger for routing.` (Electric Cobalt `#3D5BFF`, Instrument Serif Italic 70px)
  - Subtitle: `Decoupling payment identity from underlying bank rails via open internet standards.` (Slate-600, 22px)
  - 3 Stacked Horizontal Architectural Layers:
    - `LAYER 01 / APPLICATION & IDENTITY (VEYLO):` Portable identity directory (`@tomiade`, 10-digit account), WebAuthn biometric approvals, and merchant checkout SDKs.
    - `LAYER 02 / STANDARD PROTOCOL API (OPEN PAYMENTS):` Open REST API for wallet capability discovery, binding quotes, and cryptographically secure Grant Negotiation (GNAP) for subscription mandates.
    - `LAYER 03 / VALUE INTEROPERABILITY (INTERLEDGER PROTOCOL v4):` Packet-switched liquidity connectors routing value atomically without correspondent banks. Local payout partners clear into UK Faster Payments or NIP.
  - Bottom Banner: `THE INTERNET METAPHOR: Just as TCP/IP packetized information to create the internet, Interledger packetizes value to create the Internet of Value.`
- **Live Speaking Script:**
  > *"Here is the architecture that makes this possible in three distinct layers.
  >
  > At Layer 1 is Veylo: our identity directory and mobile authentication client. It translates your 10-digit number into an Open Payments resource pointer.
  >
  > At Layer 2 is the Open Payments standard: an open REST API maintained by the Interledger Foundation. It allows client apps to negotiate quotes, discover receiving wallet capabilities, and establish recurring payment mandates.
  >
  > At Layer 3 is Interledger Protocol v4. ILP does for money what TCP/IP did for data: it splits financial value into packets and routes them across independent connectors atomically.
  >
  > We eliminate correspondent banks, while partnering with licensed local payout providers to credit ordinary accounts via Faster Payments or NIP. Open protocols replace closed banking monopolies."*
- **Transition:** *"Now, let's talk about the transformative impact of this model."*
- **Key Point for Judges to Remember:** Open Payments enables discovery; Interledger routes the packets.
